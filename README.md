# Stay Strong

[Français](#français) · [English](#english)

App Android **offline** : circuit poids de corps, niveaux, agenda.

**Offline** Android bodyweight training app: circuits, levels, agenda.

## Français

### Présentation

Application Android **hors ligne** pour un circuit au poids de corps :

**Tractions → Pompes → Squats → Killy → Gainage**

Programmes par niveaux, chrono de repos, saisie des séries max, séance complète, agenda avec historique, articles, export/import.

</p>

  <em>Aperçu : démarrage → entraînement → niveaux → séance → agenda → articles</em>
</p>

### Fonctionnalités

- Circuit fixe au poids de corps
- Niveaux de progression
- Chrono de repos
- Suivi des séries / max
- Agenda et historique
- Articles
- Export / import des données
- Fonctionnement 100 % offline

### Stack

- Kotlin
- Jetpack Compose
- Android (offline first)

### Build

```bash
# Android Studio, ou
./gradlew assembleDebug
```

**Offline** Android app for a bodyweight circuit:

**Pull-ups → Push-ups → Squats → Wall sit → Plank**

Level-based programs, rest timer, max sets logging, full session flow, agenda with history, articles, export/import.
