# Stay Strong

English · [Français](README.fr.md)

**Offline** Android bodyweight training app: circuits, levels, agenda.

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

## Overview

**Offline** Android app for a bodyweight circuit:

**Pull-ups → Push-ups → Squats → Wall sit → Plank**

Level-based programs, rest timer, max sets logging, full session flow, agenda with history, articles, export/import.

## Features

- Fixed bodyweight circuit
- Progression levels
- Rest timer
- Sets / max tracking
- Agenda and history
- Articles
- Data export / import
- Fully offline

## Stack

- Kotlin
- Jetpack Compose
- Android (offline first)

## Build

```bash
# Android Studio, or
./gradlew assembleDebug
```
